# Factory presets

The editor includes a compact factory preset selector. These presets are intentionally simple parameter snapshots rather than claims of universally ideal settings. Choose **Manual** to retain the current state. Preset selection updates host-automatable parameters; saving a DAW plugin state is handled by the host. The **Save State** button also writes an XML snapshot to the user's Documents folder.

Included sounds: Natural Vocal Double, Bright Pop Double, Warm Soul, Bass Bite, Sub Power, Hollow Ghost, Square Lead, Wide Choir, Freeze A3, Live Tight, and Null / Bypass.
